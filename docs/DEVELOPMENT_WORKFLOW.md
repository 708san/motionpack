# Standard development workflow

1. Planner scopes an Issue and acceptance tests.
2. Architect checks schema and compatibility impact.
3. Main assigns bounded implementation tasks to specialist subagents.
4. Functional/Visual QA, Security Auditor and Reviewer provide independent evidence as applicable.
5. GitHub Manager checks PR, CI and policy readiness.
6. Human maintainer approves and merges.
7. Release Manager prepares a release candidate only after explicit approval.

Do not fabricate test results or confuse code review with a separately enforced security permission.
