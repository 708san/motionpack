# ADR-0001: Repo governance
Status: accepted for pre-alpha.

## Decision
One main Codex coordinator plus 11 bounded development subagents, PR-based workflow, GitHub Actions evidence, and human-controlled merges/releases. Versioned editable data format and offline runtime remain independent of AI services and gameplay.

## Rationale
Prevent contradictory edits and unsupported confidence about security, compatibility and visual quality.

## Consequences
Instructions do not enforce permission isolation. GitHub protection rules, CI and human approval must enforce actual boundaries.
