# MotionPack

An experimental, engine-independent, editable 2D animation asset format and runtime.

**Status:** pre-alpha. The data format, player, and authoring tools are subject to change.

This public repository is under active development. No software license has yet been selected; public visibility alone does not grant permission to reuse the source.

Development aims:
- Editable, portable layers, rigs, timelines, effects and variants
- Offline-capable playback without a particular game engine
- Non-destructive authoring and source preservation
- Automated format, compatibility, performance, visual and security checks
- Optional AI-based authoring skills, separate from the core runtime

Contributions and security reporting guidance will be added in the bootstrap PR.
